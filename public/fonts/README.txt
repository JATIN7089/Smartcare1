Aquitha Font Directory for SmarTCARE
======================================
Place your Aquitha font files here:
- Aquitha.woff2 / Aquitha.woff / Aquitha.ttf (Regular 400)
- Aquitha-Medium.woff2 / Aquitha-Medium.woff / Aquitha-Medium.ttf (Medium 500-600)
- Aquitha-Bold.woff2 / Aquitha-Bold.woff / Aquitha-Bold.ttf (Bold 700-900)

The application has @font-face rules configured in `src/index.css` and `tailwind.config.js` with local system fallbacks so it renders consistently and smoothly.
